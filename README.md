# sher-parsi-data

Poem data for «شعر پارسی» (https://github.com/NavidBerahmand/sher-parsi): the Ganjoor poets that don't fit in the main site's 1 GB GitHub Pages limit.
Served with GitHub Pages at https://navidberahmand.github.io/sher-parsi-data/ and read by the main site from `../sher-parsi-data/data/`.

Data © Ganjoor (https://ganjoor.net, github.com/ganjoor/ganjoor-data), bundled in the site's per-book format by `tools/bundle.py` in the main repo.
